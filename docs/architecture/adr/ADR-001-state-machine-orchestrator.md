# ADR-001: Выбор детерминированного конечного автомата (State Machine) на Python для оркестрации агентов

* **Статус:** Принято
* **Дата:** 20.11.2026
* **Контекст:** Система SavvyShopper выполняет многошаговый исследовательский конвейер: уточнение параметров запроса, поиск веток форумов, генерация динамического чек-листа рисков, нормализация товарных карточек (SKU Matching) и сборка аналитической справки. Вычисления выполняются на локальной LLM `qwen2.5:14b` с ограничением по видеопамяти (NFR-002).

## Рассмотренные альтернативы
1. **Фреймворки автономных агентных графов (LangGraph, CrewAI):**
   * *Плюсы:* Готовые абстракции для циклических рассуждений и динамического вызова инструментов (Tool Calling).
   * *Минусы:* Избыточная сложность для линейного конвейера; локальные модели уровня 14B склонны ошибаться при автономном выборе следующего узла графа и нарушать формат вызова функций; высокий порог входа при написании детерминированных unit-тестов (КТ-3).
2. **Детерминированный конечный автомат (State Machine) на чистом Python:**
   * *Плюсы:* Жесткий контроль последовательности шагов; прозрачная передача типизированных данных (Pydantic-моделей) между этапами; минимальные накладные расходы и простая изоляция каждого шага в автотестах.
   * *Минусы:* Отсутствие встроенного визуального графа отладки «из коробки» (компенсируется логированием переходов состояний в БД).

## Принятое решение
Использовать **детерминированный конечный автомат на чистом Python** в сочетании с принудительным выводом JSON (Structured Outputs в Ollama + валидация через Pydantic v2). Языковая модель используется исключительно для семантической обработки текста на каждом шаге, но не управляет потоком выполнения программы.

## Последствия и компромиссы
* **Положительные:** Гарантируется отсутствие бесконечных циклов генерации и перерасхода VRAM (NFR-002); обеспечивается 100% покрытие логики переходов unit-тестами в `pytest`.
* **Отрицательные:** При добавлении сложных нелинейных сценариев в будущих инкрементах потребуется явное расширение таблицы переходов состояний в коде оркестратора.
