# SavvyShopper

**Локальный мультиагентный конвейер для глубокого исследования товаров, фильтрации рекламного шума и анализа рыночных предложений.**

## 💡 Мотивация
Часто, сталкиваясь с проблемой покупки какой-то недешевой вещи, занимаюсь изучением рынка - чтением форумов, просмотрами обзоров для поиска оптимального варианта - и тут возникает естественная мотивация в **автоматизации этого исследовательского пайплайна**.
Ниже представлена попытка реализации подобного сервиса.


**SavvyShopper** выступает в роли независимого ИИ-консультанта для сложных покупок. Сервис избавляет пользователя от многочасового ручного исследования: принимает свободный запрос, сам производит "ресерч", вытаскивая реальные недостатки моделей из некоммерческих обсуждений,
 и выдает краткий результат анализа с ссылками для потенциальной покупки.

## 🛠️ Технологический стек
*   **Backend & API:** Python 3.11+, FastAPI, Uvicorn, Pydantic v2.
*   **Оркестрация ИИ:** Детерминированный конечный автомат (State Machine) на чистом Python + локальный движок Ollama (`qwen2.5:14b`).
*   **Поиск и очистка данных:** `duckduckgo-search` (Search Engine Dorking), `trafilatura`, эвристический антирекламный фильтр.
*   **База данных:** PostgreSQL 16 (асинхронный драйвер `asyncpg`, SQLAlchemy 2.0, Alembic).
*   **Frontend (MVP):** Streamlit (чат-интерфейс).
*   **Инфраструктура и тесты:** Docker, Docker Compose, Pytest, `respx` / `vcrpy`.
